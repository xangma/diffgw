# Archived unvalidated ROM prototype

These files preserve the former prototype and its tests for development history.
They are not installed, imported by the release packages, or run by the maintained
release test suite. Their original paths are retained below this directory, and
their historical imports and default output paths have not been modernized.

The Torch `.pt` and NumPy `.npz` tables were previously bundled with the package;
they are not the official SEOBNRv4 ROM HDF5 tables. No physical-accuracy or
official-model parity qualification is established by this archive. Restore and
adapt code only on a feature branch while developing a validated replacement.
