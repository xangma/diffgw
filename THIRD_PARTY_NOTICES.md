## Cook Kerr-mode data — ODC-By-1.0

Contains information from Gregory B. Cook, *Kerr Modes: Phase fixed
gravitational QNMs and TTMs*, v4 (2025), made available under the Open Data
Commons Attribution License v1.0.

- Database: https://doi.org/10.5281/zenodo.16801267
- Licence: https://opendatacommons.org/licenses/by/1-0/
- Method citation: Cook and Zalutskiy, *Phys. Rev. D* **90**, 124021 (2014),
  https://doi.org/10.1103/PhysRevD.90.124021.

The runtime now uses independent numerical solutions generated by TorchWave's
own Kerr equation solver. The former Cook-derived runtime arrays have been
removed; `kerr_qnm_author.py` is only a compatibility import. The independent
generator, interpolator, and newly generated data are original MIT work.
Historical validation reports still describe the former representation.

The following external validation files contain selected author data or
metadata derived from it and carry the same attribution and licence. They are
kept outside source and wheel distributions under
`~/.cache/torchwave/external-validation/cook` and are used only when
`TORCHWAVE_EXTERNAL_VALIDATION_DIR` is explicitly set:

- `kerr_qnm_author_holdout.json`
- `kerr_qnm_author_validation.json`
- `kerr_angular_author_samples.json`

Retain this attribution and licence URI when redistributing these data or
derived databases. Publicly used outputs that constitute a Produced Work under
ODC-By-1.0 require the associated notice specified in section 4.3. The database
licence governs database rights; it does not license independent rights in
individual contents or apply to the software operating on the database.

## PhenomXPNR calibration sources and unresolved inherited tensors

The equation text used by the independent XPNR scalar component reference is
from Hamilton et al., arXiv:2507.02604v1, and Thompson et al.,
arXiv:2312.10025v1; both arXiv HTML records state CC BY 4.0. The 80 single-spin
BAM configurations described as the angle calibration set are publicly listed
by the BAM catalogue. Its minimal and complete Zenodo releases, records
7673796 and 7677297, state CC BY 4.0. DiffGW does not bundle those waveform
archives in source or wheel distributions.

The numerical `A1..A4`, `B0..B5`, and `Bf` arrays already present in
`src/torchwave/approximants/pnr_coefficients.py` and
`src/jaxwave/approximants/pnr_coefficients.py` are not printed in either paper.
Their independent origin and redistribution terms have not been established.
The papers point to files in LALSuite, which is GPL-2.0-or-later, but this audit
did not inspect, copy, translate, or fit coefficients from LAL source and does
not infer a licence for the inherited arrays. Pinned LAL binaries are used only
as black-box comparison oracles. See
`docs/waveforms/research/imrphenomxpnr.md` for hashes and qualification scope.

## IMRPhenomT author formulas and calibration expressions — MIT

`src/diffgw_core/phenomt_fits.py` transcribes the aligned dominant- and higher-mode fit branches from
`phenomxpy/phenomt/fits.py`; the native Torch and JAX reconstruction follows
`internals.py` and `numba_ansatze.py` alongside the published model equations.
The code has been adapted to framework-native tensor algebra, differentiable
matching and batching; no runtime dependency on phenomxpy or LALSuite is used.
