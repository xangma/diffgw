## Cook Kerr-mode data — ODC-By-1.0

Contains information from Gregory B. Cook, *Kerr Modes: Phase fixed
gravitational QNMs and TTMs*, v4 (2025), made available under the Open Data
Commons Attribution License v1.0.

- Database: https://doi.org/10.5281/zenodo.16801267
- Licence: https://opendatacommons.org/licenses/by/1-0/
- Method citation: Cook and Zalutskiy, *Phys. Rev. D* **90**, 124021 (2014),
  https://doi.org/10.1103/PhysRevD.90.124021.

The runtime now uses independent numerical solutions generated by TorchWave's
own Kerr equation solver. The former Cook-derived runtime arrays have been
removed; `kerr_qnm_author.py` is only a compatibility import. The independent
generator, interpolator, and newly generated data are original MIT work.
Historical validation reports still describe the former representation.

The following external validation files contain selected author data or
metadata derived from it and carry the same attribution and licence. They are
kept outside source and wheel distributions under
`~/.cache/torchwave/external-validation/cook` and are used only when
`TORCHWAVE_EXTERNAL_VALIDATION_DIR` is explicitly set:

- `kerr_qnm_author_holdout.json`
- `kerr_qnm_author_validation.json`
- `kerr_angular_author_samples.json`

Retain this attribution and licence URI when redistributing these data or
derived databases. Publicly used outputs that constitute a Produced Work under
ODC-By-1.0 require the associated notice specified in section 4.3. The database
licence governs database rights; it does not license independent rights in
individual contents or apply to the software operating on the database.
