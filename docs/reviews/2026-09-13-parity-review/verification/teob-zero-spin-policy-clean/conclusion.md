# Zero-spin PN spin-order policy control

With zero-valued spins, the omitted public default and explicit PNSpinOrder=0 are separate attribution controls: the explicit PA-only output is compared on exact elapsed indices to the current analytic pre-NQC cache and saved default PA, while the explicit full-TD control is compared to omitted/default native and saved public TD. That control returned 4089 samples versus the cached 4087, so its TD comparisons are refused without truncation or alignment. This alternative public policy is not frozen parity; any difference can include branch, target, trajectory, timing, or reconstruction effects.

The report records actual epochs, lengths, sample spacing, exact elapsed-grid checks, and source/input hashes.
