# TEOB target and convention audit

**Scope.** This is a source-only audit of the clean NQC, merger, postmerger, ringdown, and conditioned-waveform paths. No LAL/upstream source was read and no oracle run was used.

## Normalization and signs

The merger assembler constructs `amplitude_rw = amplitude/(nu*sqrt(24))` (and the same auxiliary quantity) before forming the NQC matrices (`teob_merger_nqc_clean.py:799-805`). Its 2017 target helper explicitly promises the same `A_RW=|Psi_22|/nu` convention (`:322-339`), with provenance recorded as Nagar–Riemenschneider–Pratten 2017, Appendix A, Tables II/IV and Eq. A3 (`:81-89`). The lower-level `rw_normalize_22` helper only divides `h22` by `sqrt(24)` (`teob_nqc_clean.py:552-563`); the additional `/nu` is deliberately supplied by the merger assembler. The standalone 2018 target provider has a separate version and fit contract and is unused by this NQC assembly (`teob_postmerger.py:110-133`). Its abbreviated amplitude docstring alone does not establish a normalization difference; this audit finds no normalization defect in the active path.

For `h=A exp(-i phase)`, the NQC factor is `(...)*exp(+i B)`, so the corrected phase and positive frequency are `phase-B` and `phase_dot-B_dot`; the matching RHS uses `base.frequency-target.frequency` (`teob_nqc_clean.py:526-549`; merger solve `teob_merger_nqc_clean.py:829-847`). Corrected modes are reconstructed as signed amplitude times `exp(-i corrected_phase)` in the merger path. The postmerger exponent `exp(i*(phibar-omega1*tau-phase0))` has decreasing argument and therefore the same positive-frequency convention (`teob_postmerger.py:16-19, 212-223`).

## Units and events

EOB times are initial-total-mass units. The postmerger code uses `tau=(t-merger_time)/(M_f/M)` and accepts `final_mass=M_f/M` (`teob_postmerger.py:136-150, 212`). The conditioned adapter converts physical sampling by `dt_geom=dt/M_seconds`, while its start angular frequency is `pi*M_seconds*f_start` (`teob_conditioned_waveform_clean.py:579, 677-691`). Thus mass scaling occurs once at the physical/EOB boundary and again only as the remnant-mass QNM time scale.

Event provenance is distinct: (1) adaptive continuation's `peak_event_time` is the accepted frequency-decrease endpoint and is used for the public epoch (`teob_conditioned_waveform_clean.py:717-727`); (2) grid NQC peak is `argmax` on the auxiliary orbital-frequency grid, with `t_nqc=t_peak-1` and a grid index (`teob_merger_nqc_clean.py:814-847`); (3) continuous NQC peak is an accepted-series spline peak, also with `t_nqc=peak-1` (`:818-834`); (4) ringdown grid independently fits a seven-knot orbital-frequency peak, sets merger=`peak-3`, match=`peak-1`, and snaps attachment to a joined knot; continuous uses the explicit accepted peak, exact match=`peak-1`, and exact attachment boundary (`teob_ringdown_assembly_clean.py:481-532, 787-813`). There is no separate NR amplitude-peak finder in these paths: the NR-informed amplitude is a fit target at the extraction point, not an event definition. Provenance is the cited 2017 NQC and 2018 postmerger papers, with remnant fit inputs explicit; no hidden source selection occurs.
