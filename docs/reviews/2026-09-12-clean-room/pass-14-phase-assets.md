# Pass 14: XHM phase-fit assets and node indexing

Date: 2026-09-13. This bounded review uses the supplied paper and local
ancillary files, plus the primary arXiv ancillary-file index and the missing
author `p6` file. It does not use implementation source, translated ports,
generated C, notebooks, git history, verification outputs, or numerical
oracles.

## Decision

Eq. (5.5) identifies each phase-fit target `F_i` with the physical quantity
`d phi_Int_lm / d f` at a Table VII collocation frequency. The primary assets
do not state an additional relative-phase subtraction, normalization, or
rescaling for the `p_i` expressions. This establishes the quantity named by
the paper, but does not by itself certify that no unreported preprocessing was
applied before the author fits were written. No direct source mismatch with
the native p6 expressions was found.

The native default nonmixing solve remains the source-consistent mapping named
by the paper:

```text
nodes:   [f1, f2, f3, f4, f6]
targets: [p1, p2, p3, p4, p6]
```

The existing native assembly already implements this mapping. No phase runtime
edit is warranted in this pass.

## Primary evidence

* Section V.B, Eq. (5.4), gives the intermediate phase-derivative ansatz. For
  nonmixing `(2,1)`, `(3,3)`, and `(4,4)`, it sets `a_3 = 0`, leaving five
  coefficients.
* Eq. (5.5) states that the five right-hand sides `F_i` are the phase
  derivative evaluated at each intermediate collocation frequency, obtained
  through the parameter-space fits. It does not define a relative phase,
  subtraction, or rescaling for these targets.
* Table VII defines `f1` through `f6`; Fig. 8 labels them as
  `[C1,C2,E2,E3,E4,E5]` and states that the default subset is
  `[C1,C2,E2,E3,E5]`. Thus the default five nodes are `[f1,f2,f3,f4,f6]`.
  The alternative sparse-calibration subset is `[f1,f2,f4,f5,f6]`.
* Eq. (4.11) and Eq. (4.13) fix the integrated phase and its low-frequency
  relative-phase constant. They do not alter the intermediate derivative
  targets in Eq. (5.5).
* The primary arXiv ancillary listing explicitly includes p1 through p6 for
  all three nonmixing modes under `ParspaceFits/PhaseFits/{21,33,44}`:
  <https://arxiv.org/abs/2001.10914>. The archived `ParspaceFits/README`
  identifies the phase-fit notebook as the producer of the phase functional
  forms; the notebook itself was not read.
* In each of the three author p6 files, the first expanded numerical
  expression is textually identical to the native
  `XHMParameterFits.phase_p6_{21,33,44}` expression after only these syntax
  changes: Mathematica `\\[Eta]` to `eta`, `^` to `**`, `*^` scientific
  notation to `e`, and whitespace removal. There is no outer factor or
  additive term around the expanded expression. The author expressions use
  only `\\[Eta]` and `S`; the native API's `chi1` and `chi2` arguments are
  unused by these p6 fits. The Mathematica tail expressions interpolate the
  fitted `f` coefficients with mode-specific factors, and their expanded
  expressions are the ones compared above.
  This is correspondence to the archived first expanded expression only;
  the assets do not establish that it is the selected production branch under
  every calibration condition.
* This resolves numerical author provenance for p6 in all three modes. It
  does not resolve hidden fit-input preprocessing, because neither the paper
  nor the README defines how any unreported preprocessing would have entered
  the generated expressions.

## Remaining boundary

The paper says to switch to `[f1,f2,f4,f5,f6]` where there are fewer
calibration waveforms, but it gives no parameter-space criterion for that
condition. Table V contains amplitude veto regions; it is not a phase-fit
sparse-switch rule. A phase sparse-switch implementation would therefore
require an additional primary author mapping or metadata that is not present
in the supplied assets. No switch is inferred from numerical behaviour.

Likewise, the expression match and Eq. (5.5) do not prove that the fit data
were formed without a subtraction or normalization upstream of the author
assets. The claim here is limited to the named Eq. (5.5) quantity, exact p6
expression provenance, and the unresolved metadata gaps.

The independent fixture is regenerated by
`tests/data/generate_xhm_phase_author_samples.py` using 80-digit scalar
`Decimal` arithmetic over the archived expressions. Its `S` values are
computed from the listed `eta`, `chi1`, and `chi2`, including an equal-mass
sample.
