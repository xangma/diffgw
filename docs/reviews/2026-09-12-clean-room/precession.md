## Corrected equations and conventions

* The Wigner small-d matrix now has the signs tabulated in Pratten Appendix A, including `d^2_(1,2)=+2 cos^3(beta/2) sin(beta/2)` and `d^2_(2,1)=-2 cos^3(beta/2) sin(beta/2)`. The inherited generic matrix was transposed relative to that convention. Projection uses the `m'=+2` column for spin-weight -2 harmonics, and the cross polarization has the `+i` prefactor of E18/E19.
* The physical in-plane effective spin is `S_perp=m1^2 chi_p`, from Eqs. 4.3–4.4 and 4.9. The coefficient `A1` belongs in the definition of chi_p and must not be multiplied into this physical spin again. `atan2(S_perp,L+S_parallel)` preserves the small-cone limit without imposing an artificial minimum beta.
* The 3PN angular momentum uses `Sigma_l=m2 chi2z-m1 chi1z` (G6), with the 3PN truncation G10a–d,f–g. The previous combination weighted dimensionless spins incorrectly and included the 3.5PN spin-orbit term in a function claiming 3PN. Version 101 selects 2PN nonspinning L; 102 selects 3PN spinning L, as in Table III. NNLO coefficients remain the inherited G7–G9 implementation; their source pointers were corrected from Appendix B to Appendix G.
* Pv2 now canonically orders masses and complete spin vectors, fixes the geometric chi_p normalization, broadcasts scalar masses with batched inputs, preserves the zero-cone limit, and handles DC angles safely. Its inherited frame/projection mapping is retained: a complete prescription-specific Pv2 reference-frame derivation remains deferred. An attempted wholesale replacement with XP C16 geometry was reverted after independent verifier feedback identified a regression; no numerical residual or fitted offset was used to alter the replacement. Only the current HEAD copy was used to restore this inherited file; historical revisions were not explored.
* The C4 observer azimuth is `pi/2-phi_ref`. Relative to the inherited aligned carrier at zero azimuth, the mode conversion is `exp(i*m*pi/2)=i^m`. The inherited blanket minus only supplied that factor for m=2. Applying `i^m` before rotation now gives continuity to the same aligned carrier for every supported mode. This factor follows from the spherical-harmonic azimuth transformation; it was not fitted to an external waveform.
* XPHM evaluates NNLO/MSA Euler angles at the mode's SPA orbital frequency `2*pi*f/m`, as explicitly required following E18/E19. The reference spins continue to be specified at the common dominant-harmonic reference frequency. Previously all m used the m=2 evaluation frequency.
* Scalar masses with batched spin/extrinsic inputs now broadcast before ordering and angle evaluation. DC samples use finite reference-frequency angles before multiplication by the carrier's zero support, preventing `0*NaN` and preserving finite gradients.
* In the experimental ODE engine, `epsilon=-gamma` gives `d epsilon=+cos(beta) d alpha` (Pratten 3.1). The old sign was the gamma sign. Frequency integration now starts each requested frequency at the spin data's actual f_ref, integrates spin and L including the leading radiation flux rather than holding J fixed during radiation reaction, and integrates the minimal-rotation angle during RK4. Each target is an independent initial-value problem, so changing the requested output grid cannot change initial conditions. The maximum velocity step 0.001 is a numerical integration choice, **not** a fitted model coefficient. No global error bound or convergence certification is asserted. Its standalone interface requires positive frequencies; the waveform wrapper handles DC through finite reference angles.

## Unresolved model compatibility

* MSA 220/223 remains an **incomplete, experimental secular approximation**. It lacks the elliptic oscillation of S^2, the associated nutation, and oscillatory MSA corrections to the Euler angles. The existing root validity gate, PN root evolution, initialization constants, secular coefficients, and fallback boundaries are not a certified reproduction of either complete published version. A RuntimeWarning is emitted when selecting this path. Equal-mass and degenerate-root cases retain the inherited NNLO fallback.
* Public XP/XPHM signatures retain `precession_method='msa', prec_version=102`; the numeric version selects NNLO. `prec_version=None` also resolves to 102, while the paper Table III default is 223. Selecting the method string `nnlo` converts numeric 220/223 to 102. This contradictory legacy default is preserved for API compatibility and is not called paper-default compatibility.
* Pv2 retains its inherited prescription-specific frame/projection mapping, which is not independently certified and is not replaced by XP C16 offsets. XP/XPHM convention 1 currently implements C16 XP reference offsets. Table IV option 1 instead requires the distinct published Pv2 alpha initialization. Legacy convention options 0/5/6/7 remain callable but do not reproduce the complete Table IV angle/carrier-phase combinations. Version options 103/104 and unrecognized numeric versions retain a legacy Newtonian-L branch rather than the stated 4PN prescriptions; 221/222/224 and their distinct failure/initialization semantics are not implemented. `phi0` handling in the precessing projection is also incomplete. These options must not be advertised as validated equivalents merely because they execute.
* The aligned carriers are not regenerated using precession-corrected final spin/ringdown quantities. Pratten IV D and Table V distinguish NNLO chi_p-based and MSA precession-averaged prescriptions; both are missing from this implementation.
* The numerical ODE is a separate experimental approximation, not an implementation of paper MSA 223. Its inherited spin dynamics omit black-hole self-spin quadrupole couplings. Its XPHM integration still lacks a fully consistent observer/J-frame adapter and mode-specific ODE SPA angle evaluation. It must not be counted as an independent way to obtain the published model.
* The one-spin NNLO beta uses an effective spin; generic two-spin beta does not necessarily close to the physical total-spin reference geometry. A faithful complete two-spin MSA implementation is needed. Inherited source declarations have not been accepted as proof of independently verified provenance.
