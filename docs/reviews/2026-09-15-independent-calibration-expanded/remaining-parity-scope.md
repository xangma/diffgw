# Remaining parity scope after the independent `(3,3)` pilot

## Finding

The frozen v3 artifact (SHA-256 `ade377c62a57a5d9cff513e34f22b0fe43677177a0c1577a9a4af5ad3b8aa561`) is a usable **nonspinning `(3,3)` ringdown amplitude fit**, but it is not an XHM calibration provider. Its JSON identifies the model as `XHM-v2 Eq.42 (3,3) ringdown amplitude only`, stores `sigma_33` and `|a_lambda|`/`lambda` coefficient polynomials in `x=4 eta-1`, and records `chi1=chi2=0` because the qualified inputs are near-nonspinning ([`nr33-calibration.json`](../2026-09-15-independent-calibration-v3-search/nr33-calibration.json), [`fit_nr33_amplitude_pilot.py`](../../../scripts/fit_nr33_amplitude_pilot.py):355-408). The v3 review reports sub-percent held-out agreement for this amplitude slice while explicitly leaving phase, spinning accuracy, other modes, and runtime promotion open ([`README.md`](../2026-09-15-independent-calibration-v3-search/README.md):3-14, 42-46).

## Fixed quality policy compatibility

The v3 amplitude calibration already applies the fixed quality policy: all seven cases pass post-peak duration ≥150M, extraction and resolution L2 ≤1%, preprocessing variation ≤0.2%, primary reference-spin norm ≤1e-4, and eccentricity ≤1e-3. The screen covers two resolutions and N2/N3 at each retained level, with the highest-resolution N3 as primary ([`README.md`](../2026-09-15-independent-calibration-v3-search/README.md):18-34; [`quality-screen-round1.json`](../2026-09-15-independent-calibration-v3-search/quality-screen-round1.json)). The numerical convergence and preprocessing checks provide a starting point for future studies. A spinning study must preregister a different physical-spin domain: the present spin ≤1e-4 gate explicitly excludes substantial spin. Other modes need their own mode-specific quality measurements. It does not by itself solve the new requirements: complex phase/time-gauge validation, spin-parameter coverage, mode-specific extraction and mixing checks, or independent holdouts for each expanded fit.

## Scope conclusion

Aligned spins are accepted by the runtime and appear in the PN pieces, but the independent artifact supports only the nonspinning `(3,3)` amplitude subcomponent. Clean phase and generic Kerr helpers provide algebra and QNM evaluation, not calibrated data. The hard blockers are new converged complex NR datasets, phase/time-gauge definitions, mode-specific fits (including `(3,2)` mixing targets), and an explicit runtime provider boundary; no code change should claim the requested expanded parity before those records and holdouts exist.
