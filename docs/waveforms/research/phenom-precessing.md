# Phenom precession: provisional component ledger

## Scope and status

This research ledger, anchored to foundation commit 5bc907d, covers IMRPhenomP/Pv2, XP, XPHM, and the repository's XPHM-SpinTaylor and XPNR routes. It does not create a WaveformDefinition, certify full models, or cover SEOBNR. Aligned-spin carriers are [D](../../math/imrphenomd-waveform.md) for P/Pv2 and [XAS](../../math/imrphenomxas.md) for XP. XPHM and its angle variants use the unresolved [XHM mode ledger](phenom-higher-modes.md). Each row below is research-only until the exact gates in the final section pass.

Primary mathematics: [Schmidt, Hannam & Husa (2012)](https://doi.org/10.1103/PhysRevD.86.104063) and [Hannam et al. (2014)](https://arxiv.org/abs/1308.3271) for PhenomP twisting; [Pratten et al. (2021), arXiv:2004.06503v2](https://arxiv.org/html/2004.06503v2) for XP/XPHM (Secs. III–IV, Apps. A–G); [Hamilton et al. (2021), arXiv:2107.08876](https://arxiv.org/abs/2107.08876) for PNR angles; and [Colleoni et al. (2025), arXiv:2412.16721](https://arxiv.org/html/2412.16721) for XPHM-SpinTaylor (Sec. II.2). Version-specific LAL behavior is a reference implementation rather than an independent paper equation.

## Inputs, conventions, and options

All precessing routes take two 3-vector dimensionless spins in addition to mass, distance, inclination and extrinsic phase/time inputs. A complete option tuple must pin frequency grid, f_ref, phi0/observer azimuth, phic, tc, phasing convention, spin and mass ordering, L/J/N source frames, Euler offsets, carrier calibration, selected modes, and final-spin rule. In [Pratten et al.](https://arxiv.org/html/2004.06503v2), h=h_+−ih_× (Eq. 1), the Fourier transform uses exp(−2πift) (Eq. 3), gamma obeys dgamma/dt=−cos(beta)dalpha/dt (Eq. 7), and inertial/coprecessing modes rotate through Wigner D matrices (Eqs. 8–10). Those signs and frame choices matter to complex comparisons.

The paper's Table 4 distinguishes conventions 0, 1, 5, 6 and 7 through alpha/epsilon offsets and where phiRef enters the carrier. Convention 1 uses the Pv2 alpha initial angle and zero carrier phiRef. Table 5 and Eqs. 39–42 distinguish chi_p, a single transverse spin, vectorial transverse spin, and MSA averaged remnant choices. The native final_spin_mod=2 and 3 routes must not be silently interchanged; the reference also permits an option 1 which native XP/XPHM do not expose. XPHM's negative-m contributions are generated by symmetry when twisting the selected positive-m coprecessing modes (Pratten App. F).

The Hamilton PNR paper's complete co-precessing waveform is not identical to this repository's composition: the native XPNR name pairs NR-tuned PNR angles with the native XHM carrier. That mapping is explicit in both [PNR engines](../../../src/torchwave/approximants/precession_pnr.py); a match to LAL XPNR on selected polarizations does not certify equality with every construction in the original Hamilton paper. Likewise, the optional XPHM ODE method is experimental native functionality and has no paper-option equivalence established here.

## Implementation mapping

Native call graph: public [Torch](../../../src/torchwave/waveforms.py) or [JAX](../../../src/jaxwave/waveforms.py) dispatcher → named P/Pv2, XP or XPHM implementation → D, XAS or XHM carrier → chosen angle engine → Wigner rotation/projection. XPHM-SpinTaylor and XPNR aliases set the method before calling XPHM. The XPNR coefficient arrays live in [Torch](../../../src/torchwave/approximants/pnr_coefficients.py) and [JAX](../../../src/jaxwave/approximants/pnr_coefficients.py); a coefficient file existing in two frontends is not an independent calibration.

The [Pv2 source-frame checks](../../../tests/test_phenompv2_sourceframe_clean.py), [XP aligned-boundary checks](../../../tests/test_xp_aligned_boundary_clean.py), [SpinTaylor checks](../../../tests/test_imrphenom_xphm_spintaylor.py), and [PNR checks](../../../tests/test_imrphenom_xpnr.py) identify implementation branches. The last two include optional LAL/PyCBC optimized-over-time/phase match tests, which measure a different property from complex waveform error.

## Evidence and limitations

The [frozen case manifest and provenance](../../provenance_ledger.md#3-reference-evidence-by-model) report Pv2 1/1 catalog plus 1/1 holdout, and XP 1/1 plus 1/1, passing the declared complex relative L2 ≤ 10^-6 and mismatch ≤ 10^-8 thresholds for those configurations. They do not certify arbitrary P/Pv2 or XP variants. XPHM has 0/1 in each strict full-waveform set. SpinTaylor and XPNR are outside the frozen counts: optional tests define minimum plus-polarization matches of 0.98 over 20–300 Hz for three SpinTaylor cases and 0.99 over 20–400 Hz for four XPNR cases. These are acceptance thresholds, not a reported domain-wide result and not complex mode accuracy.

Known comparability gaps: [Colleoni et al.](https://arxiv.org/html/2412.16721) also introduce an updated coprecessing amplitude, whereas this native SpinTaylor route uses the current XHM carrier; the native SpinTaylor module headers miscite its publication as PRD 111, 064025 (the [published article](https://doi.org/10.1103/PhysRevD.111.104019) is 104019). Torch/JAX XPHM default methods differ; Pv2 class aliases and public routes differ; XP clean v223 is conditional; LAL App. F has options and multibanding not represented by native arguments; ODE, SpinTaylor and PNR are additional angle routes; and all XPHM routes inherit XHM's failed strict whole-waveform gate and calibration uncertainty. Differentiability of an implementation is not an independently checked derivative of the published model.

## Reproduce the checks

Inspect the cited source, dispatchers, companion XHM ledger and [historical manifest](../../model_manifest.json). Local smoke checks can use the four named test files above with the repository pytest setup; optional LAL/PyCBC comparisons require those dependencies. This ledger did not rerun the frozen reference suite.

A six-section executable specification requires **one explicitly named option tuple per branch**, with: (1) pinned source versions and independently computed effective-spin, angle, Wigner, carrier and remnant equations; (2) exact frames, spin/mass ordering, reference and Fourier conventions; (3) branch-specific Torch/JAX values and derivatives, RK convergence for SpinTaylor, fit-hash/derivative checks for PNR, and aligned/transitional limits; (4) same-option LAL complex mode and polarization catalog/holdout checks with recorded L2 and mismatch tolerances, while reporting optimized matches separately; (5) separate NR physical validation for physical-accuracy claims; and (6) reproducible commands, dependency and fixture hashes, option arguments and observed numerical outcomes. XPHM cannot be promoted until the relevant XHM components pass their own gates. No unqualified P, Pv2, XP, XPHM, SpinTaylor or XPNR catalog record follows from the evidence above.
