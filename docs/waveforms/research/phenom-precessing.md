# Phenom precession: provisional component ledger

## Scope and status

This research ledger, anchored to foundation commit 5bc907d, covers IMRPhenomP/Pv2, XP, XPHM, and the repository's XPHM-SpinTaylor and XPNR routes. It does not create a WaveformDefinition, certify full models, or cover SEOBNR. Aligned-spin carriers are [D](../../math/imrphenomd-waveform.md) for P/Pv2 and [XAS](../../math/imrphenomxas.md) for XP. XPHM and its angle variants use the unresolved [XHM mode ledger](phenom-higher-modes.md). Each row below is research-only until the exact gates in the final section pass.

Primary mathematics: [Schmidt, Hannam & Husa (2012)](https://doi.org/10.1103/PhysRevD.86.104063) and [Hannam et al. (2014)](https://arxiv.org/abs/1308.3271) for PhenomP twisting; [Pratten et al. (2021), arXiv:2004.06503v2](https://arxiv.org/html/2004.06503v2) for XP/XPHM (Secs. III–IV, Apps. A–G); [Hamilton et al. (2021), arXiv:2107.08876](https://arxiv.org/abs/2107.08876) for PNR angles; and [Colleoni et al. (2025), arXiv:2412.16721](https://arxiv.org/html/2412.16721) for XPHM-SpinTaylor (Sec. II.2). Version-specific LAL behavior is a reference implementation rather than an independent paper equation.

## Inputs, conventions, and options

All precessing routes take two 3-vector dimensionless spins in addition to mass, distance, inclination and extrinsic phase/time inputs. A complete option tuple must pin frequency grid, f_ref, phi0/observer azimuth, phic, tc, phasing convention, spin and mass ordering, L/J/N source frames, Euler offsets, carrier calibration, selected modes, and final-spin rule. In [Pratten et al.](https://arxiv.org/html/2004.06503v2), h=h_+−ih_× (Eq. 1), the Fourier transform uses exp(−2πift) (Eq. 3), gamma obeys dgamma/dt=−cos(beta)dalpha/dt (Eq. 7), and inertial/coprecessing modes rotate through Wigner D matrices (Eqs. 8–10). Those signs and frame choices matter to complex comparisons.

The paper's Table 4 distinguishes conventions 0, 1, 5, 6 and 7 through alpha/epsilon offsets and where phiRef enters the carrier. Convention 1 uses the Pv2 alpha initial angle and zero carrier phiRef. Table 5 and Eqs. 39–42 distinguish chi_p, a single transverse spin, vectorial transverse spin, and MSA averaged remnant choices. XPHM's negative-m contributions are generated by symmetry when twisting the selected positive-m coprecessing modes (Pratten App. F).

The Hamilton PNR paper's complete co-precessing waveform is not identical to this repository's composition: the native XPNR name pairs NR-tuned PNR angles with the native XHM carrier. That mapping is explicit in both [PNR engines](https://github.com/xangma/diffgw/blob/5bc907d/src/torchwave/approximants/precession_pnr.py); a match to LAL XPNR on selected polarizations does not certify equality with every construction in the original Hamilton paper. Likewise, the optional XPHM ODE method is experimental native functionality and has no paper-option equivalence established here.

## Implementation mapping

Native call graph: public [Torch](https://github.com/xangma/diffgw/blob/5bc907d/src/torchwave/waveforms.py) or [JAX](https://github.com/xangma/diffgw/blob/5bc907d/src/jaxwave/waveforms.py) dispatcher → named P/Pv2, XP or XPHM implementation → D, XAS or XHM carrier → chosen angle engine → Wigner rotation/projection. XPHM-SpinTaylor and XPNR aliases set the method before calling XPHM. The XPNR coefficient arrays live in [Torch](https://github.com/xangma/diffgw/blob/5bc907d/src/torchwave/approximants/pnr_coefficients.py) and [JAX](https://github.com/xangma/diffgw/blob/5bc907d/src/jaxwave/approximants/pnr_coefficients.py); a coefficient file existing in two frontends is not an independent calibration.

The [Pv2 source-frame checks](https://github.com/xangma/diffgw/blob/5bc907d/tests/test_phenompv2_sourceframe_clean.py), [XP aligned-boundary checks](https://github.com/xangma/diffgw/blob/5bc907d/tests/test_xp_aligned_boundary_clean.py), [SpinTaylor checks](https://github.com/xangma/diffgw/blob/5bc907d/tests/test_imrphenom_xphm_spintaylor.py), and [PNR checks](https://github.com/xangma/diffgw/blob/5bc907d/tests/test_imrphenom_xpnr.py) identify implementation branches. The last two include optional LAL/PyCBC optimized-over-time/phase match tests, which measure a different property from complex waveform error.

## Evidence and limitations

The [frozen case manifest and provenance](../../provenance_ledger.md#3-reference-evidence-by-model) report Pv2 1/1 catalog plus 1/1 holdout, and XP 1/1 plus 1/1, passing the declared complex relative L2 ≤ 10^-6 and mismatch ≤ 10^-8 thresholds for those configurations. They do not certify arbitrary P/Pv2 or XP variants. XPHM has 0/1 in each strict full-waveform set. SpinTaylor and XPNR are outside the frozen counts: optional tests define minimum plus-polarization matches of 0.98 over 20–300 Hz for three SpinTaylor cases and 0.99 over 20–400 Hz for four XPNR cases. These are acceptance thresholds, not a reported domain-wide result and not complex mode accuracy.

Known comparability gaps: [Colleoni et al.](https://arxiv.org/html/2412.16721) also introduce an updated coprecessing amplitude, whereas this native SpinTaylor route uses the current XHM carrier. Torch/JAX XPHM default methods differ; Pv2 class aliases and public routes differ; XP clean v223 is conditional; LAL App. F has options and multibanding not represented by native arguments; ODE, SpinTaylor and PNR are additional angle routes; and all XPHM routes inherit XHM's failed strict whole-waveform gate and calibration uncertainty. Differentiability of an implementation is not an independently checked derivative of the published model.

### XP v223 endpoint audit (2026-09-24)

For XP conventions 0 and 1, a Table 4 carrier-phase offset is not by itself a strain-phase offset. [Pratten et al., Appendix C Eqs. (67), (75), (79), and (81)](https://arxiv.org/html/2004.06503v2) also fix the observer direction, initial Euler angles, and output basis. At the aligned endpoint, the spin-2 projection depends on the combined angle `exp[2i(alpha0 + gamma0)]`, which equals `exp[2i(3*pi/2 + phic)]` in the tested source frame even though the raw exact-aligned `alpha0` chart differs from its tiny-transverse-spin chart by `pi`. The new endpoint test checks this combined identity at `phic = 0, 0.3, 0.7` and transverse spin `0` or `1e-9`. A separate test checks each generic convention's complete Torch clean waveform against public LAL over 20–511.75 Hz. The generic clean convention-0/1 strains have a relative sign in that fixture; treating only the Table 4 carrier shift as their full relative phase gave a stale assertion.

The aligned observer-azimuth route remains unresolved. For the v223/MSA-remnant default, Torch uses the clean helper at `phi0=0` but the inherited rotation route at nonzero `phi0`; JAX uses its inherited route at both values. The inherited Torch and JAX routes agree to about `1.3e-14` relative L2 on the diagnostic cases. A Torch-only aligned nonzero-`phi0` rotation of the clean zero-`phi0` waveform would restore that endpoint's expected spin-2 phase relation but would break this existing Torch/JAX agreement, so it was **not** adopted. Passing the MSA final-spin override into the inherited XAS carrier is insufficient: clean convention 1 still differs by `0.070509` relative L2 at 25, 40, and 80 Hz. At those frequencies, the clean/XAS complex plus-polarization ratios are approximately `0.997302-0.073561i`, `0.999993-0.000022i`, and `0.987079+0.160141i`. Their frequency dependence rules out a constant phase correction. Aligning JAX requires a sourced account of the clean aligned angle transport, not merely the remnant choice.

The paper's Eq. (17) has the strict aligned limit `cos(beta)=1` when transverse spin vanishes; an equation-level test preserves that source claim. Native XP v223 instead evaluates the exact-aligned auxiliary-root endpoint with a finite regularization. In the fixture below, its default near/exact strains differ by `3.61e-5` (plus) and `4.89e-5` (cross) in relative L2 at azimuth `-2`, even for transverse spin `1e-9`. Public LAL v223 reproduces this numerical jump, while the default clean exact and near strains separately agree with public LAL. The default-waveform test therefore bounds this version-specific jump rather than claiming fixed-basis waveform continuity; its convention-0 check bounds the same numerical effect at `2.55e-5`/`3.45e-5`. The XPHM assertions remain unchanged. Public LAL convention 0 has an additional near-aligned phase threshold around transverse spin `1e-9`, distinct from the default auxiliary-root effect. Neither numerical behavior changes the paper's strict beta limit.

Two XP tests remain open in the combined precession suite: the convention-6 cross-route assertion (`1.73e-2` relative at one sample) and the nonzero-`phi0` exact-aligned phase relation (`7.05e-2` relative L2). These remain failing gates.

The [reference-closure follow-up](xp-v223-reference-closure.md) separates the published Appendix C Eq. (79) vector identity from the v223 composed-strain behavior. It records the distinct provenance of the `259/72`, `427/72`, and compatibility-derived `259/75` coefficients and checks the measured XP/XAS reference-frequency ratio against public LAL directly. The equation-level identity remains a strict gate.

The audit ran on `len` with Torch 2.14.0+cu130, JAX 0.11.2, LAL 7.7.1, and LALSimulation 6.2.1; the LALSimulation extension SHA-256 was `e816879d23e652e8b3928496d6fd261de0832b5c3781c50e33a458042495b42e`. The diagnostic fixture used `(m1,m2)=(40,20) Msun`, `(chi1,chi2)=((0,0,0.4),(0,0,-0.2))`, `distance=500 Mpc`, `inclination=0.7`, `phic=0.3`, `f_ref=40 Hz`, `prec_version=223`, and `final_spin_mod=3`. The dense generic oracle fixture is specified in [`test_xp_aligned_boundary_clean.py`](../../../tests/test_xp_aligned_boundary_clean.py). Standalone backend diagnostics must set `PYTHONPATH=src` to import this checkout rather than an installed package.

The [nonpublic JAX generic-angle diagnostic](../../../src/jaxwave/approximants/precession_msa_v223_generic.py) implements the intrinsic spin cubic, nutation phase, secular and oscillatory angles from [Chatziioannou et al., Eqs. (21), (24), (51), (65), and Apps. B, D, F](https://arxiv.org/abs/1703.03967v3), with the opening angle and remnant identity from [Pratten et al., Sec. IV and App. G](https://arxiv.org/abs/2004.06503v2). It names the native-v223 compatibility choices separately: reference spin flux contractions, q² nutation coefficient, pole continuation, nonconserved-spin 3PN opening angular momentum, and total-mass-squared remnant normalization. The [focused test](../../../tests/test_jax_clean_v223_generic_angles.py) compares intermediate values, final angles, remnant, and six spin derivatives against the Torch clean kernel for the generic `(40,20)` fixture and independent `(48,17)` holdout. On `len` with the versions above, all five checks pass; the angle differences for the first fixture are at most `4e-15`. This establishes intrinsic Torch/JAX agreement at two nondegenerate unequal-mass points. Observer-frame transport, endpoint integration, public dispatch, and LAL complex strain remain separate gates.

### Nonpublic JAX v223 aligned projection (2026-09-24)

The [JAX aligned projection](../../../src/jaxwave/approximants/precession_msa_v223_projection.py) composes the [nonpublic intrinsic endpoint](../../../src/jaxwave/approximants/precession_msa_v223_endpoint.py) with the observer geometry of [Pratten et al., Appendix C](https://arxiv.org/html/2004.06503v2) and the finite-beta quadrupole projection of Eqs. (8)--(13) and Appendix A. Its split-root opening angle, inferred v223-compatible `259/75` source-frame coefficient, and exact-aligned Euler chart are compatibility prescriptions, not paper identities. `phic` is the clean carrier/source-frame phase; `observer_azimuth` is the separate public-XP-like `phi0`. For exact alignment the helper **imposes** the spin-2 `exp(-2i phi0)` SO(2) action after finite-beta projection as a physical endpoint identity; this does not assert that the current public nonzero-`phi0` route or LAL uses that prescription.

The [focused tests](../../../tests/test_jax_clean_v223_projection.py) compare geometry, Euler angles, remnant, finite-beta polarizations, and `phic` derivatives with Torch clean; they check JIT and observer-azimuth derivatives separately. On `len` with the latest-package environment, the endpoint and projection tests passed `21/21` (`PYTHONPATH=src python -m pytest -q tests/test_jax_clean_v223_projection.py tests/test_jax_clean_v223_endpoint.py`). Dense exact-aligned convention-0/1 waveforms at `phi0=0` differ from the pinned public LAL v223 option tuple by about `2.1e-10` relative L2. At fixed `phic=0.3`, `phi0=0.4`, and 25/40/80 Hz, the imposed physical endpoint differs from the current public Torch route by `1.99876278` (convention 0) and `0.0705129942` (convention 1) relative combined-polarization L2. Public dispatch is unchanged; that discrepancy and the near-aligned limit remain open gates.

## Reproduce the checks

Inspect the cited source, dispatchers, companion XHM ledger and [historical manifest](../../model_manifest.json). Local smoke checks can use the four named test files above with the repository pytest setup; optional LAL/PyCBC comparisons require those dependencies. This ledger did not rerun the frozen reference suite.

A six-section executable specification requires **one explicitly named option tuple per branch**, with: (1) pinned source versions and independently computed effective-spin, angle, Wigner, carrier and remnant equations; (2) exact frames, spin/mass ordering, reference and Fourier conventions; (3) branch-specific Torch/JAX values and derivatives, RK convergence for SpinTaylor, fit-hash/derivative checks for PNR, and aligned/transitional limits; (4) same-option LAL complex mode and polarization catalog/holdout checks with recorded L2 and mismatch tolerances, while reporting optimized matches separately; (5) separate NR physical validation for physical-accuracy claims; and (6) reproducible commands, dependency and fixture hashes, option arguments and observed numerical outcomes. XPHM cannot be promoted until the relevant XHM components pass their own gates. No unqualified P, Pv2, XP, XPHM, SpinTaylor or XPNR catalog record follows from the evidence above.
